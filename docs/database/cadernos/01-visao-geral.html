Visão geral: o que foi construído

Este caderno explica o que é o banco de dados novo, que partes ele tem e como uma informação entra nele. Sem código, sem pressa. Os outros cadernos entram em cada parte.

1. O que é um banco de dados, afinal

Analogia: a planilha é um caderno: qualquer pessoa escreve o que quiser, em qualquer linha. O banco de dados é um arquivo de fichas com um fiscal na porta. Cada ficha tem campos fixos, o fiscal confere o que entra, e ninguém arranca uma folha sem deixar registro.

Na planilha, escrever "quinhentos" na coluna de quantidade funciona. No banco, não: ele recusa, porque aquele campo só aceita número. Essa recusa é a principal diferença entre os dois mundos.

2. O mapa: quatro áreas, dezesseis fichários

O banco tem 16 tabelas. Elas se agrupam em quatro áreas. Este é o mapa que os outros cadernos vão detalhar.

3. O caminho de um apontamento

Quando alguém aperta Salvar na tela de apontamento, o dado não vai direto para a tabela. Ele passa por uma função dentro do banco, que é onde moram as regras.

Analogia: é a diferença entre entregar a mercadoria na portaria e entrar dirigindo até o estoque. O app entrega na portaria; quem guarda, confere e anota é o banco.

4. O porteiro: por que cada um vê uma coisa

Analogia: imagine que todos os funcionários peçam a mesma pasta na recepção. O porteiro entrega a pasta com folhas diferentes para cada um, conforme o crachá. Ninguém precisa confiar no programa: o porteiro está dentro do próprio arquivo.

5. Quatro coisas que o banco faz sozinho

Copia a meta do diaO apontamento guarda a meta vigente naquela data. Mudar a meta hoje não reescreve o passado.
Separa retrabalhoRefazer 4.000 peças não vira 4.000 peças novas. A produção boa e o retrabalho são contados à parte.
Marca hora extraHora extra entra na produção total, mas fica fora do cálculo de meta — senão o percentual ficaria falso.
Anota quem fezToda criação, alteração e exclusão vai para a auditoria, com o antes, o depois e o IP.

Estado de hoje: versão do banco v0.10.3, num projeto Supabase de testes. 16 tabelas, 2 consultas prontas, 27 funções, 28 regras de acesso, nenhuma tabela desprotegida. 47 testes de banco e 7 do app passando. Os 842 apontamentos que estão lá são fictícios, para conseguirmos ver as telas com dados.
